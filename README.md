## How it works

`main.ts` (Node stdlib only) writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and chmods it to 0644.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
